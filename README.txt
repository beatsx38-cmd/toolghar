ToolGhar starter website
=========================
Files:
- index.html
- style.css
- script.js

Run:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge.
3. For production, upload these files to a static host.

Included working starter tools:
- JPG -> PNG
- PNG -> JPG
- Image Compressor
- Image Resizer
- Word Counter
- Case Converter
- Percentage Calculator
- EMI Calculator
- GST Calculator
- Discount Calculator
- BMI Calculator
- Password Generator
- QR generator (uses an external QR API)

Note:
JPG -> PDF, PDF -> JPG, Merge/Split/Compress PDF and other server-heavy tools are shown in the interface but need a proper PDF processing engine/backend for production. This starter intentionally does not pretend those conversions are complete.
